স্টেপ ১: পাইথন (Python) ইনস্টল করা
১. ব্রাউজার খুলে python.org/downloads লিংকে যান এবং Download Python বাটনে ক্লিক করে ফাইলটি ডাউনলোড করুন।
২. ডাউনলোড করা ফাইলটিতে ডাবল ক্লিক করে সেটআপ চালু করুন।
৩. ⚠️ খুবই গুরুত্বপূর্ণ: সেটআপ স্ক্রিনের নিচে Add python.exe to PATH অপশনটিতে টিক চিহ্ন (Tick mark) অবশ্যই দিন।
৪. এরপর Install Now-এ ক্লিক করে ইনস্টলেশন শেষ করুন।

স্টেপ ২: প্রয়োজনীয় লাইব্রেরি (Packages) ইনস্টল করা
১. আপনার কিবোর্ডে Win + R চেপে cmd লিখে Enter চাপুন (কমান্ড প্রম্পট খুলবে)।
২. এবার নিচের পুরো কমান্ডটি একবারে কপি করে কমান্ড প্রম্পটে পেস্ট করে Enter চাপুন:

Bash
pip install pandas openpyxl pdfplumber beautifulsoup4 selenium webdriver-manager
কিছুক্ষণ সময় নেবে, সব প্রয়োজনীয় লাইব্রেরি স্বয়ংক্রিয়ভাবে ইনস্টল হয়ে যাবে।

স্টেপ ৩: ফাইল ও ফোল্ডার সাজানো
১. আপনার কম্পিউটারের যেকোনো জায়গায় (যেমন: Downloads বা Desktop-এ) একটি নতুন ফোল্ডার বানান। ধরুন ফোল্ডারের নাম দিলেন: Chalan Verify
২. আপনার আসল চালান ধারণকারী PDF ফাইলটি এই ফোল্ডারের ভেতর নিয়ে আসুন।
৩. নোটপ্যাড (Notepad) খুলে আপনার পাইথন কোডটি পেস্ট করুন এবং ফাইলটি ওই একই ফোল্ডারে challan_automation.py নামে সেভ করুন।

📌 খেয়াল রাখবেন: কোডের নিচের লাইনে যেন আপনার PDF ফাইলের সঠিক নাম দেওয়া থাকে:

Python
SOURCE_PDF = "individual 09-09-2026.pdf"  # আপনার ফাইলের নাম অনুযায়ী চেঞ্জ করবেন
স্টেপ ৪: স্ক্রিপ্ট রান বা চালু করা
১. কমান্ড প্রম্পট (CMD) খুলুন।
২. আপনার বানানো ফোল্ডারে ঢুকতে এই কমান্ডটি লিখে Enter চাপুন:

Bash
cd "C:\Users\YOUR_USERNAME\Downloads\Chalan Verify"
(আপনার ফোল্ডারের সঠিক পথ/Path বসাবেন)

💡 সহজ ট্রিক: ফোল্ডারটি খুলে উপরে অ্যাড্রেস বারে (Address Bar) সরাসরি cmd লিখে Enter চাপলে একবারে ওই ফোল্ডারে কমান্ড প্রম্পট খুলে যাবে।

৩. এবার স্ক্রিপ্টটি চালাতে নিচের কমান্ডটি লিখুন:

Bash
python challan_automation.py
💡 দরকারি টিপস:
ক্রোম ব্রাউজার: নতুন কম্পিউটারে গুগল ক্রোম (Google Chrome) ইন্সটল করা থাকতে হবে।

ড্রাইভার আপডেট: webdriver-manager ব্যবহার করার কারণে কোনো আলাদা ক্রোম ড্রাইভার ম্যানুয়ালি ডাউনলোড করতে হবে না, পাইথন নিজেই তা ডাউনলোড ও আপডেট করে নেবে।

এবার যেকোনো নতুন কম্পিউটারে চোখ বন্ধ করে এই ৪টি স্টেপ ফলো করলেই কাজ হয়ে যাবে!
